# Contributing

Thank you for your interest in DisasterMesh Sentinel.

## Before contributing

- Read the README.
- Review SECURITY.md.
- Use synthetic data only.
- Never commit secrets.
- Do not test against systems without authorization.
- Check existing issues before opening a new one.

## Development workflow

1. Fork or clone the repository.
2. Create a branch.
3. Make a focused change.
4. Add or update tests.
5. Update documentation.
6. Run formatting, linting, and tests.
7. Open a pull request.

## Branch naming

```text
feature/short-description
fix/short-description
docs/short-description
test/short-description
security/short-description
```

## Pull requests

A pull request should include:

- Clear problem statement.
- Summary of changes.
- Testing performed.
- Screenshots for UI changes.
- Security or privacy considerations.
- Migration notes, if applicable.
- Documentation updates.

## Emergency-system disclaimer

This project is a prototype. Contributions must not represent the application as a certified emergency dispatch or public-safety system.
