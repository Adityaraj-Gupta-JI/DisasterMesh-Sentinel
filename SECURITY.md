# Security Policy

## Project status

DisasterMesh Sentinel is a hackathon prototype and is not certified emergency-response infrastructure.

Do not include real personal data, emergency reports, medical information, credentials, or private location data in issues or pull requests.

## Reporting a vulnerability

Please do not publicly disclose suspected vulnerabilities.

Report security issues privately to:

- Email: [SECURITY CONTACT EMAIL]

Include:

- Affected component.
- Reproduction steps.
- Impact assessment.
- Relevant logs with secrets removed.
- Suggested mitigation, if known.

Never include:

- Passwords.
- API keys.
- Access tokens.
- Private keys.
- Personal emergency data.
- Unredacted location histories.

## Safe-harbor expectations

Security testing must be:

- Non-destructive.
- Limited to systems you own or are authorized to test.
- Free of data exfiltration.
- Free of denial-of-service activity.
- Free of persistence or social engineering.
